## Wireless tools / Nexmon

Native development helpers are generated by `alpha/scripts/build_radio_helpers.py`.
The pinned upstream source, COPYING, input hashes and output hashes are retained
under `alpha/out/operator-handshake/native/`. Wireless tools and Aircrack-ng have
their own GPL obligations; the wrapper package's MIT notice does not replace them.
No native helper is bundled in the APK. Do not publish/release a ROM containing
these helpers without accompanying corresponding sources, patches and licenses.
One existing aireplay/airodump directory literal is relocated to root-private
`/data/lambda-op`; original input is hash-pinned and remains untouched. This is a
development compatibility adaptation, not a general Aircrack-ng source build.

The airodump helper is the retained Android arm64 Nexmon port reporting
`Airodump-ng 1.2 rc4`, not a newly compiled/current upstream Aircrack-ng release.
Its original SHA-256 is
`a8cccc7fca0fbd80f21024557922710398a08054255996a38eb3ea685b4fcdc0`.
The input remains in `kernel/reference/nexmon-s10/extracted/system/bin/airodump-ng`.
The development manifest records both input and adapted output hashes. Before
distribution, replace this compatibility binary with a reviewed reproducible
source build, including its corresponding source, patches and GPL notices.

The WPA indication and terminal-header layout were reviewed against the Nexmon
Aircrack-ng reference source at revision
`68720406f54ff16cad28fd3c51f2392aefad9fb7`, file
`utilities/aircrack-ng/src/airodump-ng.c`. This is reference code, not a claim that
the retained binary was reproducibly built from that revision.
