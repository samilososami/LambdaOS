as individual files for reuse. The README only displays a small selection;

The wallpaper files are the original artwork resources used by the setup
application. Their source dimensions are recorded in the manifest; the Android
wallpaper application scales/crops them for the S10 display. They are not
mislabelled as native 1440 × 3040 exports.

## How to use the archive

Files under `design` and `generated` include proposals, rejected iterations,
historical references and generated mockups. Their presence does not mean a
screen or feature is implemented in the current OS. In particular, the custom
quick-control dialog proposals were later reverted in the running system.

The selected `screenshots` were captured on the actual development phone.
The quick-settings capture shows a dedicated test network. Personal backups,
device dumps and unreviewed test captures are excluded.

Original image bytes and dimensions are preserved in the design archive.
The repository banner is a direct crop of the established LambdaOS title with
black padding; it has no slogan, mascot or powered-by text. The separate social
preview is prepared at the size recommended by
[GitHub](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).
It can be uploaded in the repository's Social preview setting.

Retained third-party licenses accompany the icons/fonts. See
[`NOTICE.md`](../NOTICE.md) for attribution and the distinction between project
artwork and external reference material. No blanket relicensing is implied.
