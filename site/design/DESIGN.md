# LambdaOS website — visual contract

## Direction

Five coordinated image concepts: `hero.png`, `system.png`, `operator.png`, `origin.png`, `development.png`.
Near-black #080808 and neutral off-white #f4f4f2; no accent color, glass, neon or gradient lettering.
Inter Variable. Hero 76–96px at wide desktop; section headings 56–72px; body 18–22px; controls 14–16px.
Maximum content width 1376px. Desktop gutters 64px, mobile 22px. Section spacing 112–144px. Thin rules, open editorial layouts; no card-grid template.

## Section order and interactions

1. Quiet original wordmark/header, native four-line headline and two links. Generated standalone S10 photograph, not an image of a web page. Technical device strip below.
2. Off-white system gallery. Four keyboard-accessible tabs, three real screenshot previews and native full-size image dialog. An additional wallpaper comparison uses the actual dark/light files and a slider; original downloads remain available.
3. Operator: open two-column text and code-native architecture diagram; expandable capability rows. Current Operator capture available in one row. Lamb checkpoint with the approved mascot, not the generated concept's inaccurate sheep.
4. First-person origin text and white folded-paper art band.
5. Development status accordion, device specification strip and repository links. No public ROM download claim.

## Icons

Arrow up/right, arrow right, plus/minus, menu/close, chevrons, expand: simple consistent 24px currentColor SVG, 1.5px stroke, square line caps. Diagram app-window, terminal and device icons use same geometry. Real Lambda brand files are reused, not redrawn.

## Copy lock / intentional corrections

Hero: “Un sistema Android dedicado a ciberseguridad.”
Support: “Diseñado alrededor del Samsung Galaxy S10. Parte de Lambda Project.”
Nav: Sistema / Operator / Proyecto / GitHub.
CTA: Explorar el sistema / Ver el código.
No extra hero eyebrow, badges or statistics.

The concept generator invented secondary headers and alternate logos/mascots. These are deliberately excluded. Actual device captures replace all invented concept UI. Per the user's copy correction, section titles are concise: “El sistema.”, “Lambda Operator.”, “La idea.” and “Desarrollo.”
Origin includes the user's requested comparison with NetHunter and correctly identifies Marcus Holloway. Claims about future support remain explicitly qualified.

## Responsive / accessibility

One column under 800px; hero image below text. Gallery central device + subtle partial side previews; no horizontal page overflow. Native dialog keyboard dismissal, tab arrow keys, reduced-motion mode, visible focus, 44px interactive targets. No auto-play carousel, forced scroll or tracking.

## Asset provenance

Screenshots and branding from the user's public LambdaOS repo. Hero and origin are generated product/editorial art, not evidence of shipping UI. Gallery captures retain source content. All images compressed to WebP without content editing. Original wallpaper downloads link to the source repo.
