Development.

LambdaOS is in alpha. The system already boots on the reference device; public distribution is being prepared.

There is no public ROM download yet. Initial releases will include requirements, instructions, SHA-256 checksums and known issues.

View releases
01System foundationImplemented

Android 15, setup wizard, boot sequence, lock screen and a consistent palette. The foundation uses LineageOS 22.2 and is tested on the reference S10.

02Kernel and hardwareIn validation

Kernel 4.14.356 with 95 modules. Monitor-mode receive is verified on the internal Wi-Fi and on the Alfa AWUS036ACH at 2.4 GHz; injection and 5 GHz are tested separately.

03Core and OperatorIn development

Shared contracts for commands and the app: arguments, permissions, states, cancellation and results. Handshake capture, WPS testing and offline cracking run in developer builds.

04LEXIn development

A Kali chroot with a slim XFCE session and a native viewer inside Operator, running on the S10. The on-screen keyboard is still in progress.

05ReleasePlanned

Signed packages, installation and recovery documentation, source code and known issues. Other devices and S10 variants have not been validated.

06LambOn hold

The checkpoint preserves the on-device model tests. Fine-tuning will resume when training can reflect the actual tools and behavior of LambdaOS.

The idea.

Sami González Kamel@samilososami

It started with Watch Dogs. I was drawn to how easily Aiden Pearce and Marcus Holloway interacted with technology from a phone.

Then I discovered Kali NetHunter. I liked what it made possible, but wanted to take the idea further: a more integrated, intuitive experience, with less switching between tools.

That is how LambdaOS began, as part of Lambda Project. I’m designing a system dedicated to pentesting and cybersecurity around the Galaxy S10, from the interface down to the hardware.
