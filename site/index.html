03Operator

One operation.
Every layer.

Lambda Operator is the control surface. Lambda Core runs typed jobs with validation, cancellation and a receipt — the same contract from the app or a terminal.

01Networks and connectivity

Wi-Fi, Bluetooth and networking, organised by task. Each operation shows what it needs, what it is doing and what it found.

Operational workflows are in development. The interface does not mean every capability is available.

02Device and radio

USB, HID, CAN and radio adapters. The kernel is validated on the S10 and support is documented by chipset and tested capability.

A compiled driver is no substitute for testing the physical adapter.

03Operations and receipts

The same operation from Operator or the terminal, with shared state, cancellation and a structured result. That is the direction of Lambda Core.

05LEX

A desktop
inside the phone.

LEX is the Lambda EXperience: a Kali XFCE desktop in a chroot, drawn by a native RFB viewer inside Operator — no web layer. The new shell is a slim session: a quiet top bar, a dock at the bottom, monochrome icons and a terminal one tap away.

06Development

Built in the open.
Released when ready.

LambdaOS is in alpha on the reference S10. There is no public ROM download yet. Releases will ship with requirements, signatures and known issues.

View releases
01System foundationImplemented

Android 15, setup wizard, boot sequence, lock screen and a consistent palette. The foundation uses LineageOS 22.2 and is tested on the reference S10.

02Kernel and hardwareIn validation

Kernel, modules and firmware. Stability, USB and adapter testing determine which capabilities are considered supported.

03Core and OperatorIn development

Shared contracts for commands and app: arguments, permissions, states, cancellation and results. Operator is built on that foundation.

04LEXIn development

A Kali chroot, a slim XFCE session and a native RFB viewer inside Operator, with a monochrome shell. Validated on the S10; the release will document the limits.

05ReleasePlanned

Signed packages, installation and recovery documentation, source code and known issues. Other devices and S10 variants have not been validated.

06LambOn hold

The checkpoint preserves the on-device model tests. Fine-tuning will resume when training can reflect the actual tools and behaviour of LambdaOS.

07Origin

It started with
Watch Dogs.

I was drawn to how easily Aiden Pearce and Marcus Holloway interacted with technology from a phone. Then I discovered Kali NetHunter. I liked what it made possible, but wanted to take the idea further: a more integrated, intuitive experience, with less switching between tools.

That is how LambdaOS began, as part of Lambda Project. I am designing a system dedicated to pentesting and cybersecurity around the Galaxy S10, from the interface down to the hardware.

08FAQ

Straight answers.

What is LambdaOS?

A pentesting-focused Android operating system built around the Samsung Galaxy S10. It combines a monochrome system interface, Lambda Operator, typed Lambda Core jobs and a Linux desktop called LEX.

Can I install it?

Not yet. The project is in alpha on the reference device. Public releases will include requirements, installation and recovery instructions, signatures and known issues.

Which devices are supported?

Only the Samsung Galaxy S10 SM-G973F (beyond1lte) has been validated. Other models and S10 variants are not supported.

Does it include Google apps?

No. LambdaOS is based on LineageOS 22.2 and ships without Google apps.

Is Lamb included?

Lamb is the on-device assistant. Its model work is checkpointed and it is not included in the current alpha ROM.

Is this legal?

LambdaOS is a tool for authorised security testing and research. Use it only on systems you own or have explicit permission to test.
